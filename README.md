# Feliz aniversario, mi amor

Un viaje para Dany. Sitio estático con animación, recuerdos, música y una dedicatoria final.

## Activar GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment → Source**, selecciona **Deploy from a branch**.
3. En **Branch**, elige **main** y **/(root)**.
4. Pulsa **Save** y espera a que termine **pages build and deployment** en **Actions**.
5. Abre [la página](https://ruben-n1.github.io/dproyect/).

La web ya está preparada en la raíz. Conserva `index.html`, `.nojekyll`, los módulos JavaScript y la carpeta `assets` juntos. La publicación desde esta rama sirve directamente estos archivos.

La música comienza al tocar **Comenzar**. Al pulsar **Sí**, salta a **2:40**; al terminar se detiene sin repetirse.

[Documentación oficial de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
